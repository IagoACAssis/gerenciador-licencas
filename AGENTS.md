# AGENTS.md

## Idioma

Este projeto usa português do Brasil em tudo: documentação, issues, comentários, código, commits e conversa. A exceção são os **nomes** dos labels, que ficam em inglês para casar com as skills; as descrições deles estão em português.

## Agent skills

### Issue tracker

As issues ficam no GitHub Issues (IagoACAssis/gerenciador-licencas) e são gerenciadas pelo `gh` CLI. Veja `docs/agents/issue-tracker.md`.

### Labels de triagem

Labels canônicos padrão, com nome em inglês e descrição em português: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. Veja `docs/agents/triage-labels.md`.

### Docs de domínio

O layout é single-context: um `GLOSSARY.md` e `docs/adr/` na raiz. Veja `docs/agents/domain.md`.
